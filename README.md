# talepkamel

This repository hosts a generated CV (Word document) for Sacha Dubois along with
the Python scripts used to produce it.

- `Sacha_Dubois_CV.docx` — the generated CV
- `generate_cv.py` — builds the Word document
- `make_photo_avatar.py` — turns a supplied photo into a circular avatar
- `make_avatar.py` — initials-based placeholder avatar generator
